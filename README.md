"Ernie's Igor tools.ipf" is a collection of routines on various topics that I wrote for my personal use.
I got tired of reinventing the wheel every time I wanted to do something so I decided to create these routines
   and make them thorough and documented so I could depend on them and have confidence that they are correct.
This is not a complete, finished product as I am continually adding routines, and it is, and probably always
   will be, a work in progress, but I am confident that the routines that are here can be relied upon.

These routines fall into several basic categories:
   Display information, which prints or makes panels of information that I often want and find useful
   Formula weight information, which calculates formula weights and displays the periodic table
   Substance properties: dry air, water vapor in air, and liquid water (I will include ice at some point)
   Particle properties: dynamics, coagulation, charging, and activation
   Miscellaneous tools - a hodgepodge of routines on various topics
   A list of all functions.

The routines require Igor 8 or later; earlier versions will be incompatible, mostly because of long names.
Some of the routines can be used as stand-alone procedures, but many are designed to be used together.
As they were coded using my user preferences, they might look different on other computers.
On a PC, the Igor window must be expanded to the full extent possible to view all of the windows.

If this file (or an alias of it) is placed in the Igor Procedure folder, then the routines will compile and a
   menu of selections will be available when Igor opens.
The location on a Mac is "Applications/Igor Pro XXX Folder/Igor Procedures/", where XXX is the Igor version number.
The location on a PC is "C:\Users\<username>\Documents\WaveMetrics\Igor Pro XXX User Files\Igor Procedures",
   but be aware there are several aliases that point to the same location.

To view the source code, select "Windows" in the upper Igor menu, then "Show", then "All procedure windows";
   doing so will open ALL procedure windows, not just this one.
This option is recommended; if you open this procedure in Igor it will cause issues because it will be already open.
